# Project Stats

**Автор:** Балюк Егор Вячеславович, группа М3116
**IDE:** Visual Studio Code
**Язык:** TypeSript

## Описание

Project Stats - показывает статистику открытой папки проекта в небольшом окне.

## Возможности

- Кнопка **Project Stats** в статус-баре (слева внизу) и команда
  «Project Stats: показать статистику» (`Ctrl+Shift+P`).
- Общее число файлов и общий размер.
- Общее число строк в текстовых файлах (`.cpp`, `.h`, `.md` и т.п.).
- Количество README-файлов.
- Количество файлов по расширениям (например, `.cpp` - 12).
- Топ-3 самых больших файла, по клику файл открывается в редакторе.
- Служебные папки (`node_modules`, `.git`, `build` и т.п.) не учитываются.
- Если папка не открыта, плагин показывает предупреждение.

## Запуск и установка

### Запустить через **F5**
1. Скачать проект: на GitHub нажать **Code → Download ZIP** и распаковать.
2. Открыть папку проекта в VS Code.
3. В терминале выполнить `npm install`.
4. Нажать **F5**. Откроется второе окно VS Code.
5. В нём открыть любую папку и нажать кнопку **Project Stats** слева внизу.

### Как установить у себя

1. В терминале в папке проекта выполнить `npx @vscode/vsce package`.
2. В VS Code нажать `Ctrl+Shift+X`, потом `···` справа вверху → **Install from VSIX...**
3. Выбрать файл `project-stats-0.0.1.vsix` и перезапустить VS Code.
