## Описание:
### Project Stats - плагин для VS Code, написанный на языке TypeScript, показывает статистику откртытой папки проекта в небольшом окошке

## Возможности плагина:
- Показывает общее число файлов в проекте
- Общий размер всех файлов 
- Общее количество строк в текстовых файлах(`.cpp`, `.h`, `.md` и тп.)
- Количество файлов по определённым расширениям(напрмиер, `.cpp` - 12)
- Топ 3 самых больших файла(по клику файл откроется в редакторе)
- Различные служебные папки в статистику не входят(`.git`, `build` и тп.)
- Если папка в данный момент не открыта, плагин покажет предупреждение

## Запуск
```bash
npm install
```
Откройте папку проекта в VS Code и нажмите **F5**. В открывшемся окне откройте
любую папку и нажмите кнопку **Project Stats** слева внизу.

## Установка как расширения
```bash
npx @vscode/vsce package
```
Затем в VS Code: панель расширений → `...` → **Install from VSIX...** → выбрать
созданный файл `.vsix`.

## Структура проекта
| Файл               | Назначение                                        |
|--------------------|---------------------------------------------------|
| `src/extension.ts` | весь код плагина с комментариями к функциям       |
| `package.json`     | описание плагина и его команд                     |
| `docs/`            | документация проекта                              |
