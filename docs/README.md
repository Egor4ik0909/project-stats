# Документация плагина Project Stats

## 1. Общее описание

Project Stats — плагин для VS Code, написанный на TypeScript. Он показывает
статистику открытой папки проекта в небольшом окне: количество файлов, размер,
строки, файлы по расширениям и самые большие файлы.

**Структура проекта:**

```text
project-stats/
├── docs/
│   └── README.md        # документация
├── src/
│   └── extension.ts     # код плагина
├── package.json         # описание плагина и его команды
└── README.md            # описание проекта
```

**Как работает плагин:**

1. При запуске VS Code вызывает функцию `activate`, которая создаёт кнопку
   «Project Stats» в статус-баре и регистрирует команду `project-stats.showStats`.
2. Пользователь нажимает на кнопку (или вызывает команду через `Ctrl+Shift+P`).
3. Плагин собирает данные обо всех файлах папки (`collectFiles`), считает строки
   (`countLines`) и формирует список для окна (`buildItems`).
4. Список показывается в окне. Клик по файлу из топа открывает его в редакторе.

Служебные папки (`node_modules`, `.git`, `out`, `dist`, `build`) в подсчёт не попадают.

## 2. Описание функций

Все функции находятся в файле `src/extension.ts`.

### `collectFiles()`

Находит все файлы открытой папки (кроме служебных) и запоминает для каждого
имя, расширение и размер.

- **Принимает:** ничего.
- **Возвращает:** список файлов (`Promise<FileInfo[]>`).
- **Пример:** `const files = await collectFiles();`

### `countByExtension(files)`

Считает, сколько файлов каждого расширения.

- **Принимает:** `files` — список файлов проекта.
- **Возвращает:** `Map<string, number>` — расширение и количество файлов.
- **Пример:** `countByExtension(files)` вернёт `Map { ".cpp" => 8, ".md" => 1 }`.

### `countLines(files)`

Считает общее число строк во всех текстовых файлах (`.cpp`, `.h`, `.md`, `.ts` и т.п.).

- **Принимает:** `files` — список файлов проекта.
- **Возвращает:** число строк (`Promise<number>`).
- **Пример:** `const lines = await countLines(files);` вернёт, например, `2297`.

### `formatSize(bytes)`

Переводит размер из байтов в читаемый вид.

- **Принимает:** `bytes` — размер в байтах.
- **Возвращает:** строку с единицей измерения.
- **Пример:** `formatSize(500)` вернёт `"500 Б"`, `formatSize(1536)` вернёт `"1.5 КБ"`.

### `buildItems(files, lines)`

Собирает строки для окна статистики: общие числа, файлы по расширениям
и три самых больших файла.

- **Принимает:** `files` — список файлов, `lines` — общее число строк.
- **Возвращает:** список строк для окна (`StatItem[]`).
- **Пример:** `const items = buildItems(files, 2297);`

### `activate(context)`

Главная функция плагина, VS Code вызывает её при запуске. Создаёт кнопку в
статус-баре и регистрирует команду. Если папка не открыта, показывает
предупреждение «Откройте папку с проектом».

- **Принимает:** `context` — контекст плагина (служебный объект VS Code).
- **Возвращает:** ничего.

### `deactivate()`

Вызывается при выключении плагина. Ничего не делает, так как очищать нечего.

- **Принимает:** ничего.
- **Возвращает:** ничего.

## 3. Запуск и установка

### Запустить через **F5**
1. Скачать проект: на GitHub нажать **Code → Download ZIP** и распаковать.
2. Открыть папку проекта в VS Code.
3. В терминале выполнить `npm install`.
4. Нажать **F5**. Откроется второе окно VS Code.
5. В нём открыть любую папку и нажать кнопку **Project Stats** слева внизу.

### Как установить у себя

1. В терминале в папке проекта выполнить `npx @vscode/vsce package`.
2. В VS Code нажать `Ctrl+Shift+X`, потом `···` справа вверху → **Install from VSIX...**
3. Выбрать файл `project-stats-0.0.1.vsix` и перезапустить VS Code.
